# Publishing FreeNM

Target repository: https://github.com/lucacarai/FreeNM

Expected website after publication: https://lucacarai.github.io/FreeNM/

FreeNM has its own local repository on the main branch, just like FreeGodel. Publish the FreeNM app folder, not the parent KripkeApps folder.

## First publication through GitHub Desktop

1. Open GitHub Desktop.
2. Select File > Add local repository.
3. Choose `C:\Users\carai\Documents\AI projects W\KripkeApps\FreeNM` and select Add repository.
4. Select Publish repository. Use the name FreeNM, select your personal lucacarai account, and uncheck Keep this code private for a public repository.
5. Select Publish Repository.
6. Open the repository on GitHub, then select Settings > Pages. Set the build and deployment source to GitHub Actions.
7. Under Actions, open Deploy FreeNM to GitHub Pages. If the first attempt failed because Pages was not yet enabled, select Run workflow on the main branch after enabling Pages.
8. Once the workflow finishes successfully, open https://lucacarai.github.io/FreeNM/.

The local repository is prepared with an initial commit. No remote is configured yet so GitHub Desktop can offer Publish repository.

## Updates

Select the FreeNM repository in GitHub Desktop, commit the changes, and select Push origin. The workflow builds, tests, and publishes the app automatically after each push to main.

The workflow builds before testing because the direct-open HTML is generated by the build and tested too. Only dist/ is uploaded to Pages. Temporary files under .local/ are ignored.

The hosted app uses relative asset paths and content hashes to refresh updated modules. A page already open during a deployment needs a reload; Ctrl+F5 forces a fresh reload on Windows.

Drawings and panel preferences are browser-local. To move a drawing from the local file to the hosted app, use Save file locally and Open on the hosted app.

## Local verification

```powershell
node scripts/build.mjs
node --test tests/*.test.mjs
```

For a development server at the published subdirectory path:

```powershell
node server.mjs --base=/FreeNM/
```

Then open http://127.0.0.1:4175/FreeNM/. This server must be started from your own Windows terminal when the assistant's environment blocks local networking.
